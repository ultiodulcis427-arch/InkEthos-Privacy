# Security Policy

## Supported content

This repository hosts the current InkEthos privacy-policy website. Security fixes are applied to the latest version on the `main` branch.

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting from this repository's **Security** tab. Include:

- A clear description of the issue and its potential impact
- Steps to reproduce it
- The affected page, file, or URL
- Relevant screenshots or logs with personal data, credentials, and secrets removed

Reports will be acknowledged as soon as practical. Valid issues will be investigated and fixed based on severity. Please allow time for a fix before publicly disclosing the issue.

For privacy requests or account-support questions, use the contact method published in the InkEthos privacy policy.
